# 3R-бот — переказ параграфа з оцінюванням

Заміна Gemini Gem для методу **3R (Read – Recite – Review)**:

1. **Read** — учень читає параграф у застосунку (або в підручнику).
2. **Recite** — текст ховається, учень переказує його боту; бот порівнює переказ з еталоном,
   ставить навідні запитання щодо пропущених ідей і не виходить за межі тексту.
3. **Review** — після завершення бот формує структурований звіт (повнота %, точність,
   самостійність, розкриті/пропущені ідеї, помилки, рекомендації).
   Звіт автоматично потрапляє в **панель викладача**, учень також може його завантажити.

Учням не потрібен Google-акаунт і немає вікових обмежень — лише посилання.

## Розгортання (Streamlit Community Cloud, безкоштовно)

1. Зайдіть на <https://share.streamlit.io> через GitHub → **Create app** → **Deploy a public app from GitHub**.
2. Repository: `Aranaur/kse-3R-app`, branch `main`, main file `app.py`.
3. **Advanced settings → Secrets** — вставте вміст [.streamlit/secrets.toml.example](.streamlit/secrets.toml.example)
   зі своїми значеннями:

| Ключ | Значення |
|---|---|
| `GEMINI_API_KEY` | безкоштовний ключ з <https://aistudio.google.com/apikey> |
| `TEACHER_PASSWORD` | пароль для панелі викладача |
| `HF_TOKEN` | fine-grained токен HF (<https://huggingface.co/settings/tokens>) з правом write на `DATA_REPO` |
| `DATA_REPO` | приватний HF dataset для завдань і звітів, напр. `aranaur/kse-3r-bot-data` |
| `GEMINI_MODEL` | необов'язково, за замовчуванням `gemini-2.5-flash` |
| `MAX_FOLLOWUPS` | необов'язково, скільки уточнень без прогресу (4) |

Без `HF_TOKEN`/`DATA_REPO` застосунок працює, але завдання й звіти зникають після
перезапуску (застосунок «засинає» після кількох днів без відвідувань і прокидається за ~30 с).

> Hugging Face Spaces (Docker) тепер вимагають PRO-підписку; [Dockerfile](Dockerfile) лишається
> для розгортання на HF PRO, Render, Cloud Run тощо.

## Як користуватися

**Викладач:** бічна панель → «Викладач» → вкладка «Нове завдання»: назва, текст параграфа
(вставити або .txt/.pdf), за бажанням — ключові ідеї та вказівки боту. Після збереження
отримаєте посилання виду `https://<app>.streamlit.app/?a=<id>` — його і даєте учням.

Завдання також можна додавати файлами в папку [assignments/](assignments/) (див. приклад).

**Учень:** відкриває посилання, вводить ім'я та клас, читає, переказує, натискає
«Завершити й отримати звіт».

## Локальний запуск

```bash
uv venv && uv pip install -r requirements.txt
GEMINI_API_KEY=... TEACHER_PASSWORD=123 uv run streamlit run app.py
```

## Обмеження безкоштовного рівня

- Gemini API free tier має ліміти запитів на хвилину/день; для класу з 30 учнів одночасно
  можуть траплятися помилки 429 — тоді варто увімкнути платний рівень (вартість мізерна).
- На free tier Google може використовувати запити для покращення моделей — не вводьте персональні дані,
  окрім імені учня. Для повної відповідності політикам KSE — платний ключ або Vertex AI.
